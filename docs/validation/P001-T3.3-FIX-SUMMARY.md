## Issues Fixed

### 1. Validation Script Bugs

**Problem:** The `cp -r "$TEMPLATES_DIR/$template/".*` command was matching `.` and `..` directories, causing cross-template pollution (express-react files inside nextjs projects).

**Fix:** Replaced with `find "$TEMPLATES_DIR/$template" -mindepth 1 -maxdepth 1 -exec cp -r {} "$output_path/" \;`

**Problem:** TypeScript, ESLint, and build checks ran from project root for express-react, using wrong tsconfig.

**Fix:** Modified checks to run from `client/` and `server/` subdirectories for express-react template.

**Problem:** Dependency check expected separate node_modules in workspace packages (doesn't happen with npm workspaces).

**Fix:** Updated check to verify npm workspace links instead of directory existence.
