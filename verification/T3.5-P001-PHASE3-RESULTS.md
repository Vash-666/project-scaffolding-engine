## Usage Examples

### Basic Usage

```bash
# Scaffold only
./scripts/scaffold-and-push.sh my-app nextjs-fullstack

# Scaffold + GitHub
./scripts/scaffold-and-push.sh --github my-app nextjs-fullstack

# Private repository
./scripts/scaffold-and-push.sh --github --private my-app nextjs-fullstack
```

### Advanced Usage

```bash
# Custom description and output directory
./scripts/scaffold-and-push.sh \
    --github \
    --description "My awesome app" \
    --output-dir ~/projects \
    my-app \
    nextjs-fullstack

# Test without making changes
./scripts/scaffold-and-push.sh --dry-run --github my-app nextjs-fullstack

# Push existing project
./scripts/github-push.sh --private /path/to/project my-repo-name
```

## Configuration

### Environment Variables

```bash
# Required for GitHub integration
export GITHUB_TOKEN="ghp_xxxxxxxxxxxxxxxxxxxx"

# Optional
export GITHUB_USERNAME="your-username"  # Auto-detected if not set
export GITHUB_REPO_VISIBILITY="public"  # Default visibility
```

### Token Setup

1. Visit https://github.com/settings/tokens
2. Generate new token (classic)
3. Select scopes: `repo`, `workflow`
4. Copy and export as GITHUB_TOKEN
