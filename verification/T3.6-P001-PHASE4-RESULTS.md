## Agent Workflow

```
User: @scaffolder create my-app nextjs-fullstack --github

@scaffolder:
├── Parse command
│   ├── project: my-app
│   ├── template: nextjs-fullstack
│   └── options: --github
├── Validate prerequisites
│   ├── Check git, npm, curl
│   ├── Check templates exist
│   └── Check GITHUB_TOKEN (if --github)
├── Execute scaffold-and-push.sh
│   ├── Generate project
│   ├── Install dependencies (~40s)
│   ├── Run quality gates
│   │   ├── TypeScript: PASS (2pts)
│   │   ├── ESLint: PASS (2pts)
│   │   ├── Build: PASS (2pts)
│   │   ├── Structure: PASS (2pts)
│   │   └── Dependencies: PASS (2pts)
│   ├── Score: 10/10
│   └── GitHub push (if requested)
├── Record in memory
└── Return results
    ├── Project name
    ├── Quality score
    ├── Repository URL
    └── Local path
```

## Usage Examples

### Basic

```bash
# Create Next.js project
@scaffolder create my-app nextjs-fullstack

# Create Express+React project
@scaffolder create my-api express-react
```

### With GitHub

```bash
# Push to GitHub
@scaffolder create my-app nextjs-fullstack --github

# Private repository
@scaffolder create my-app nextjs-fullstack --github --private

# With description
@scaffolder create my-app nextjs-fullstack --github --description "My app"
```

### Utility Commands

```bash
# Check setup
@scaffolder check

# List templates
@scaffolder templates

# Show help
@scaffolder help
```
